# AppFig SDKs

Pre-built AppFig SDKs for **iOS**, **Android**, **Unity**, and **React Web**.  
Download the SDK for your platform from the folders above and drop it directly into your project.

# Unity SDK terminal command
curl -L https://github.com/smartconfigui/AppFig-SDKs/raw/main/unity/AppFigUnitySDK.dll --create-dirs -o Assets/Plugins/AppFig/AppFigUnitySDK.dll
# Android SDK terminal command
curl -L https://github.com/smartconfigui/AppFig-SDKs/raw/main/android/AppFigAndroidSDK.aar --create-dirs -o app/libs/AppFigAndroidSDK.aar
# iOS SDK terminal command
curl -L https://github.com/smartconfigui/AppFig-SDKs/raw/main/ios/AppFig.xcframework.zip -o AppFig.xcframework.zip && unzip AppFig.xcframework.zip -d Frameworks/ && rm AppFig.xcframework.zip

## What is AppFig?

AppFig is a **client-side feature engine** for apps and games — instant feature flags, audience targeting, and real-time rule evaluation with zero latency.
